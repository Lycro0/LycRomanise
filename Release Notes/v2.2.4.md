## LycRomanise v2.2.4

### A new default setup
New installs start with a cleaner look: the Minimal layout with soft white words that lift and glow as they're sung, a slimmer strip, romanized lyrics only, the dark app theme, and the web view turned on.

If you already use LycRomanise, this update switches your look and display settings to the same setup once. Your strip's position and lock, per-song timing, chosen lyrics, Spotify login, Spicy Lyrics key and imported lyrics folder stay as they are. You can change anything back in Settings → Appearance.

### Fixed
- The tray icon shows the new Ly icon. It was still showing the old one, because the tray could not read the new icon file at small sizes.

### Removed
- The "Show where lyrics came from" option. The source is never shown on the strip.

Because the web view is now on by default, Windows may ask whether to let LycRomanise through the firewall the first time it starts. Allow it if you want to see the lyrics on your phone or in OBS.

Download `LycRomanise_Setup.exe` (the installer, recommended) or `LycRomanise.exe` (portable). If you're on v2.x, the app will offer this update itself.
