## LycRomanise v2.0.1

- Fixed: upgrading from v1 when it was installed for all users (in Program Files) left both versions installed. The installer now removes the old v1 copy after installing v2. Windows asks for permission once, because removing an all-users install needs admin rights.
- Fixed: if v1 was set to start with Windows, v2 now keeps that setting instead of switching it off.
- The Start with Windows switch in Settings now always shows what Windows will actually do.

Everything from [v2.0.0](https://github.com/Lycro0/LycRomanise/releases/tag/v2.0.0), the full rewrite, is included.

**Downloads:** `LycRomanise_Setup.exe` (installer, recommended) or `LycRomanise.exe` (portable). If you're on v2.0.0, the app offers this update by itself.
