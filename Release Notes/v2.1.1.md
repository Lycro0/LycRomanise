## LycRomanise v2.1.1: fixes, and the QR code is back

### New
- **QR code for the web view** in Settings → Web view & OBS: scan it with your phone's camera to open the lyrics (same Wi-Fi).

### Fixed
- The strip could stay on screen after pausing the music. It stayed up as a preview whenever the Settings window was open, even minimized or in the background; now that only happens while you're using Settings.
- A player that closed or stopped answering could leave the strip up as if it were still playing.
- Turning "Show lyrics on this PC" (or the web view) on from the tray or Ctrl + Alt + H was undone by the next change in Settings, such as editing the appearance.

**Downloads:** `LycRomanise_Setup.exe` (installer, recommended) or `LycRomanise.exe` (portable). If you're on v2.x, the app offers this update by itself.
