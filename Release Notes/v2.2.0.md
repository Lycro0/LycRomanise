## LycRomanise v2.2.0: new look, and a round of fixes

### New
- **New icon and branding**: a black and red Ly icon. The app is now black and white with red accents (Settings, the tray, the installer).
- **The web view is black and white** too, with a red progress bar.
- **Where lyrics came from is hidden by default.** Turn it on in Settings → Lyrics & romanization if you want it. (Spicy Lyrics asks for its credit to be shown, so lyrics from it still show a small credit.)
- A new trailer in the README.

### Fixed
- **Wrong lyrics for some songs**: NetEase could match a different song by the same artist that happened to be the same length (for example YOLO showing Whiplash's lyrics). It now checks the title, and its old cached answers are looked up again.
- **The OBS song title file (`LycRomanise.txt`)** could stop updating or show a broken name. It is now written whole and swapped in, retried if OBS has it locked, saved so Korean and Japanese names show correctly, and rewritten at once when you change its format.
- **The full lyrics window froze** when opened while a song was already playing.
- **The data folder is back to `%APPDATA%\LycRomanise`** (from `LycRomanise Modern`). Your settings, cache and imported lyrics are moved across automatically and the old folder is removed. If an OBS Text source reads `LycRomanise.txt`, point it at the new folder.
- Start with Windows is stored as "LycRomanise" again.

**Downloads:** `LycRomanise_Setup.exe` (installer, recommended) or `LycRomanise.exe` (portable). If you're on v2.x, the app offers this update by itself.
